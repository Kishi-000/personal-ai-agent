# DEMO-01｜条件付きスマートフォン選定

## 1. デモの目的

個人適応型AIエージェントが、利用者の要望を構造化し、外部情報の探索、必須条件の検証、独立したLLM監査、最終再評価まで実行できることを確認する。

## 2. 入力した課題

日本国内で新品購入できるSIMフリーAndroidスマートフォンを比較する。

必須条件：
- 税込10万円以内
- 内蔵ストレージ256GB以上
- おサイフケータイ対応
- 防水防塵対応

希望条件：
- バッテリー持ちが良い
- できるだけ軽い

## 3. 実行結果

- 問題のJSON構造化：成功
- 不要な追加質問の抑制：成功
- Web検索の必要性判定：True
- 候補探索：5機種
- 必須条件のPASS / FAIL / UNKNOWN判定：実行
- 独立したLLM監査：実行
- 監査結果を反映した最終再評価：実行

監査では、motorola edge 50 proのストレージ容量に関する根拠不足を検出し、該当項目をPASSからUNKNOWNへ修正した。

## 4. 検証上の限界

独立監査は別のLLMによる回答・根拠の整合性確認であり、外部情報の真偽を完全に保証するものではない。

価格や在庫などの変動情報は、実際の購入時点で再確認が必要。
